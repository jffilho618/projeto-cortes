## 2. Fichas "regra 9" (faz / origem / mantenedor / licença / custo / executa)

### taste-skill (`design-taste-frontend`)
- **Faz:** direção de arte para **sites institucionais** (paleta e fontes sorteadas por ramo, layouts de hero testados, fotos reais, efeitos WebGL só para tech/gaming) + checagem automática em Chrome headless (4–5 larguras) + "finish gate".
- **Origem:** https://github.com/Leonxlnx/taste-skill (v2.5.1, 2026-11-07).
- **Mantenedor:** Leonxlnx (pessoa física, com patrocinadores).
- **Licença:** MIT. **Custo:** grátis.
- **Executa:** ao instalar via `npx skills` → roda o CLI `skills` da Vercel (Node 22.20+, telemetria ligada por padrão, copia arquivos para `.agents/skills`/pastas dos agentes). Ao usar → ~10 scripts Node 22+, Chrome headless, ffmpeg opcional; copia `assets/` para o projeto; **Stop hook** (`gate.mjs`); rede para Google Fonts, fotos e ícones extras.
- **Encaixe no painel:** fraco — o alvo declarado é site de empresa com hero, não ferramenta de operação.

### impeccable
- **Faz:** vocabulário de design com comandos (`critique`, `audit`, `polish`, `bolder`, `quieter`, `typeset`, `live`…), detector determinístico de 62 regras de "slop", modo live no navegador, gera `PRODUCT.md`/`DESIGN.md`.
- **Origem:** https://github.com/pbakaus/impeccable (skill v4.10.0, engine v0.1.28, nov/2026) · site impeccable.style.
- **Mantenedor:** Paul Bakaus (único mantenedor no npm).
- **Licença:** Apache-2.0. **Custo:** grátis.
- **Executa:** `npx impeccable install` (Node) detecta as ferramentas, escreve **hooks** (PostToolUse + Stop no Claude; sessão/conclusão no Gemini); **binário nativo** baixado para `~/.impeccable/bin/` (verificado por checksum); rede para o catálogo impeccable.style a cada design novo + telemetria opcional; modo `live` pode lançar `claude`/`codex` **sem permissões** se não for travado com `IMPECCABLE_LIVE_COPY_AGENT=chat|off`; grava `.impeccable/` no projeto.
- **Encaixe:** forte — já é o líder de design no CLAUDE.md; os artefatos `.impeccable/` existem, mas a skill não aparece instalada hoje.

- **Comparação controlada e independente** (mesmo brief, várias skills, avaliação cega). Só achei vitrines dos autores (taste, impeccable) e listicles sem método. Um post da uxplanet diz ter testado 3 skills, mas é paywalled e não foi lido.

- Data de atualização das páginas de docs do shadcn MCP e do 21st MCP.
- Skill de design voltada especificamente a **dashboard/painel operacional** com evidência. As skills populares miram landing pages e sites; o `frontend-design` oficial cita dashboard só como exemplo de contraste.
- A metodologia por trás dos números da Snyk/ToxicSkills (o artigo lido não traz).
