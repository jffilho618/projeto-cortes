**Leitura para a decisão (inferência minha, não é achado):** as quatro bases headless (Base UI, Radix, React Aria, Ark) estão vivas e têm licença permissiva. Para um visual próprio, a melhor opção é uma base **sem estilo**. Mantine e HeroUI já vêm com estética própria, que teria de ser desfeita. O shadcn em 2026 funciona mais como distribuidor de código, com registry, presets e `eject`, sobre Base UI ou Radix. Nesse papel ele não obriga ao visual padrão. O "genérico" vem de aceitar os defaults (ver F2(b)). Esta pesquisa **não** comparou a qualidade de acessibilidade entre as bases: não li auditorias nem docs de a11y.

**Leitura para a decisão (inferência minha):**
- **Motion (MIT) + View Transitions + CSS no estilo transitions.dev:** é a camada de movimento mais coerente para painel de trabalho, com licenças limpas e reduced-motion tratado.
- **GSAP:** é grátis, mas a licença é proprietária e revogável. Para uso próprio não há conflito com a cláusula anti-Webflow, mas a licença fere a preferência por código open-source.
- **react-bits e Animate UI:** a Commons Clause não atrapalha o uso próprio. Mesmo assim, os dois não são OSI, e isso deve ser registrado.
